Generated by Poiesis from the `web-app` archetype: a browser frontend, an HTTP
API and a Postgres database, wired together and healthy before any feature code
was written.

## Run it

```bash
cp .env.example .env      # optional; defaults work
docker compose up -d --build
```

Then open <http://localhost:8081>. The banner in the header turns green when the
browser has reached the API and the API has reached the database.

## Layout

| Path | What lives there |
|---|---|
| `frontend/app.js` | Browser code. Story interfaces render here. |
| `frontend/index.html` | Page shell. |
| `backend/app/routes.py` | API endpoints. Story logic goes here. |
| `backend/app/models.py` | ORM models. |
| `db/init.sql` | Schema. Must stay in step with `models.py`. |
| `tests/` | Pytest suite, run from the repository root. |

`backend/app/main.py` and the `/health` endpoint are fixed: deployment
verification depends on them.

## Test

```bash
pip install -r requirements.txt
python -m pytest -q
```

The suite runs without Postgres — the database engine is created lazily, so
importing the app never opens a connection.
